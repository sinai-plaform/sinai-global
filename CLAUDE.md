# SINAI Global (sinai-global.com)

Company site: home + solutions in 10 languages (generated), the magazine (rendered on request), hand-written legal and Downline HQ pages. README.md describes the generated pages; its "GitHub Pages" line is outdated.

## Hosting and ship
Cloudflare Pages project `sinai-global`, direct upload. **A git push alone does not update the site.**
1. Edit `build/i18n/<lang>.json` / `build/build.mjs`, then `node build/build.mjs` (bump `const V` when a file in `assets/` changed).
2. `python3 ~/.claude/skills/landing-page-builder/scripts/perf_lint.py .` → 0 errors.
3. Commit, `git push origin HEAD:main`, `zsh deploy-cf.sh`.
4. Live check: `curl -s https://sinai-global.com/ | grep -o 'sg.css?v=[0-9]*'` shows the new `V`; for the magazine `curl -s -o /dev/null -w '%{http_code}' https://sinai-global.com/magazine` → 200.

`deploy-cf.sh` uploads the committed tree (HEAD): the site goes to `site/`, and `functions/` + `server/` sit beside it so wrangler compiles them as Pages Functions instead of serving their source.

## Magazine (2026-11-14)
- Addresses: `/magazine` (English, root language), `/xx/magazine`, articles `/magazine/<slug>` and `/xx/magazine/<slug>`, no trailing slash. Plus `/magazine/sitemap.xml` and `/magazine/llms.txt`.
- Rendered on request by `functions/magazine/[[path]].js` and `functions/[lang]/magazine/[[path]].js` → `server/mag-core.js` (engine, identical copy in the sinai-club repo — change both) + `server/mag-site.js` (this site's page). `_routes.json` keeps every other address a static file; a new function route must be added there.
- `server/mag-chrome.js` is generated by the build (header, footer, fonts, the `mag` words of every language). After changing i18n, run the build before shipping.
- Styles: `assets/mag.css` on top of `sg.css` (light and dark). Default cover: `assets/magazine/cover-default.jpg`.
- Articles: `public.magazine_articles` where `site = 'global'`, Supabase project `ooxdupeihzvbzudibaoi`. Categories: `ai`, `automation`, `build`, `growth`. Schema, cover trigger and the publishing job (`magazine_publish_due`, pg_cron every 10 min, pings IndexNow): `supabase/migrations/20261114_magazine_articles.sql`. Cover copy: edge function `magazine-cover` (`supabase/functions/`).
- Pages are cached 10 minutes at Cloudflare; a new article needs no deploy.
- Local look without the database: `~/Documents/Claude/Projects/SINAI Global/_tools/magazine/` — `render-test.mjs` (static pages into `_magtest/`, delete it afterwards) and `mock-db.mjs` + `npx wrangler pages dev . --binding MAG_DB=http://localhost:8795/`.
- Articles quote the prices of `/solutions`. When `PRICES` changes, fix the articles that mention them (`select slug, lang from magazine_articles where site = 'global' and body_md ~ '₪|\$'`).
